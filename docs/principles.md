# 创作原则

- **取意**：理解色彩关系、媒介感、光线、节奏、情绪和空间密度，而非机械套用物件位置。
- **不取形**：不要把独特角色、姿态、构图、标志性装饰、文字或水印作为需要保留的模板。
- **质量不退让**：独立性不等于随机化或故意做丑；保留用户真正喜欢的审美原因。
- **透明而不装作认证**：记录来源和授权状态，如实披露 AI 参与；不使用未经验证的原创度百分比。
- **尊重两边**：既尊重原作者的劳动，也尊重普通人通过 AI 获得的表达能力。

建议评估：使用许可明确的参考图进行成对生成；让评审者分别判断审美保真、具体表达相似程度、新图质量。报告主观评价和限制，不将其等同于法律结论。
