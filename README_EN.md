# Inspired, Not Copied

An image-reference Skill for AI-assisted creation. Its aim is to preserve the aesthetic qualities people value in a reference while encouraging independent visual expression rather than simple object swaps.

Read [SKILL.md](./SKILL.md) and add it to a compatible AI workflow, or use it as project-level generation instructions. The first release is a prompt/workflow specification, not an automated similarity detector or legal clearance service.

Three goals: **aesthetic fidelity, expressive independence, and output quality**. No guarantee of originality or non-infringement is implied. Attribution is not permission. For details see the [Chinese README](./README.md) and [limitations](./docs/limitations.md).
