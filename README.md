# Inspired, Not Copied · 取意，不取形

**让 AI 学习参考图的审美，而不是简单复制它的具体表达。**

一个中文优先、面向 AI 参考图创作的开源 Skill（v0.1）。

## 为什么做它？

看到喜欢的画，我们常想把它的视觉感觉迁移到自己的新场景。但“相同画风，换个主体”很容易滑向局部换皮；反过来，过度回避相似也可能让新图失去原本吸引人的清晰感、色彩关系和情绪。这个 Skill 试着兼顾三个目标：**审美保真、表达独立、创作质量**。

## 使用方式

将 [`SKILL.md`](./SKILL.md) 加入支持自定义 Skill 的 AI 工作流，或将其内容作为图片生成前的系统/项目规范。提供参考图与新主题，例如：

> 参考这张图的色彩关系、线条和清新感，创作一张程序员夜间桌搭。请执行 Inspired, Not Copied 流程。

具体安装方式取决于使用的 AI 产品；本仓库暂不宣称跨平台自动安装或自动检测。

## 它做什么

1. 提取参考图的抽象视觉语言。
2. 识别不宜照搬的具体表达。
3. 为新主题重新设计构图、主体、场景与光线。
4. 在可检查输出时进行定性相似性复核。
5. 对公开发布提供来源、授权与 AI 使用披露建议。

## 它不做什么

不是法律意见、版权数据库、自动侵权检测器、原创度评分器，也不保证生成结果不侵权。风格与具体表达的边界会因作品和司法辖区而不同。标注来源不等于取得授权。

## 项目状态

v0.1：规范和提示流程。尚无经验证的相似性降低指标或自动化测试结果。欢迎画师、设计师、AI 创作者提供反馈；公开示例应优先使用自有、授权或许可明确的素材。

详见 [`docs/principles.md`](./docs/principles.md) 与 [`docs/limitations.md`](./docs/limitations.md)。
